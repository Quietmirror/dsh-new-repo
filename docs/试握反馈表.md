# V0.1 试握反馈表

打印件：`out/v0.1/fingertip_v01_trial_grip.stl`。先贴好五个圆点脚贴（记录脚贴厚度），在常用鼠标垫上以平时的指握姿势使用。
主键、侧键和滚轮在 V0.1 中都是固定的，这一轮只评价外形和能否够到，不评价点击手感和回弹。

每项打分 1–5（3 = 合适），写清方向和大致幅度（mm），例如“握宽 2：太宽，约窄 2 mm”。
