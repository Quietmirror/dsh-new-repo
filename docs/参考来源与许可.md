# 参考来源、实际查看的文件与许可

本项目 V0.1 的几何全部由 `cad/` 中的 Python 参数化代码从零生成。**没有复制任何参考项目的源码、STL 或 CAD 几何**；只借鉴了结构思路，并引用了少量从参考文件中读出的数值（下文逐条注明出处）。
今后若直接复用这些项目的源码或几何，需要按下文保留署名并遵守相应许可证。

检出时间：2026-10-14（浅克隆 `--depth 1`）。

## 1 badjeff/olliebella

- 地址：https://github.com/badjeff/olliebella ，提交 `03441afe9fff`（2026-09-16）
- 许可：**CERN-OHL-P v2**（宽松型开源硬件许可）。复用其设计文件时需保留版权与许可声明。

实际查看：

| 文件 | 查看方式 | 读到的内容 |
|---|---|---|
| `README.md` | 全文 | 设计原则（指握/抓握、无螺丝拼插、1.1 mm 壳、外骨骼）、BOM、“lens-to-surface ~2.4 mm (±0.2)，脚贴按 ~0.65 mm 计”、5 个 7.5 mm 圆点脚贴 |
| `STLs/*.stl`（22 个） | trimesh 读入，量包围盒/体积 | shell 47.2×65.6×22.3 mm、4.26 cm³；base 42.5×51.1×4.4 mm；wheel Ø23.9；rear skate Ø7.5；lens U mount 10.2×7.55×2.0；m1/m2 按键 21.2×40 |
| `STLs/base.stl` | Z=0.05 截面 + 渲染 | 底板是一整片贴床的平面镂空格栅（1 个外轮廓、13 个孔，截面积 ≈1161 mm²）；四角各一个 Ø≈7.5 圆形脚贴区，后部中央另有独立的 rear skate，共 5 点 |
| `STLs/shell*.stl` | 截面宽度、渲染 | 外骨骼式壳体，顶部、侧面大窗口；pinky-rest / thumb-rest 变体 |
| `CADs/*.f3z` | 解压读 `DesignDescription.json` | 组件清单：EC05E1220401 编码器、paw3950-surface、XIAO nRF52840、Kailh CMI627301D07、MSK-1153 拨动开关、301230 LiPo、PH2.0 2P 插座。`.f3d` 几何为 Fusion 专有格式，本环境无法解析 |
| `imgs/sen-fore.png`、`imgs/p5.jpeg` | 看图 | 传感器板平卧于底板中部框内；整机外观与重量（约 24.6 g） |

采用的结构：紧凑比例；底部为“周边框 + 斜向承力筋 + 中部传感器框”的平面格栅；**五个圆点脚贴 = 四角 + 后中**；滚轮在前部两主键之间。
引用的数值（标注 B）：圆点脚贴 7.5 mm、脚贴厚 ~0.65 mm、lens-to-surface 2.4 mm、主键微动 6×6×7.3（BOM）、301230 电池（BOM）、PH2.0 插头。

## 2 pseudoku/Kotinos

- 地址：https://github.com/pseudoku/Kotinos ，提交 `7b367537a29e`（2026-06-10）
- 许可：**GPL-3.0**。若今后复制其 SCAD 代码或 STL 几何，衍生文件须按 GPL-3.0 发布并保留署名。

实际查看：

| 文件 | 读到的内容 |
|---|---|
| `README.md` | HSK Pro 指握壳改装、BOM（7 个 6–7 mm 圆形脚贴、M1.4 螺丝、IDC 排线） |
| `Build/MainBuild.scad` | 用 `hull()` 连接球节点形成开放杆系骨架（`joint_radius = 1.1`）；脚贴圆柱 d7.5 底面落在 Z=0，杆件底高约 0.5；`SupportJointGround` 用连续杆件把所有脚贴连成一体；手部姿态 `wrist_tent/tilt` 驱动各指“paddle”接触面位置 |
| `Build/DataHand.scad` | 可调手部参数：掌骨/各指节长度、屈曲角、指粗；中性姿态与握持姿态两套角度 |
| `Build/HandGenerator.scad` | `PlaceOn()` 沿手指运动链放置子物体（指尖接触面随手参数移动） |
| `Build/PaddleSurfaceGenerator.scad`、`Data*Paddle.scad` | 用 Bezier 曲面片 + 法向加厚 1.5 mm 生成指腹接触面（拇指、无名指、小指、食指深/浅两种） |
| `Build/HSK_PCB.scad` | HSK Pro 主板 39×26、食指板、微动包络 5.8×6.5×12.8、编码器 —— **只作对照，不沿用孔位** |
| `STL/Kotinos.stl` 等 | 89.6×65.5×39.6 mm；44 个壳体片（杆件布尔前未合并） |

采用的结构：开放骨架思路（以最少材料连接脚贴、接触面和受力点）；指部接触区做成连续光顺曲面片；接触区位置参数化（本项目用位置/尺寸/深度参数表达，没有用 Kotinos 的运动链模型，因为用户的指节长度和握姿尚未测量）。
**未采用**：HSK Pro 的主板孔位、paddle 拼装方式。

## 3 badjeff/paw3395-pcb

- 地址：https://github.com/badjeff/paw3395-pcb ，提交 `b71e346fc04e`（2026-06-18）
- 许可：**CERN-OHL-P v2**。

实际查看：

| 文件 | 读到的内容（标注 M = 从文件实测） |
|---|---|
| `README.md` | 兼容 PAW3395DM-T6QU / PAW3950DM-T5QU；LOAE-LSI1 或 LM19-LSI 镜头；3.3 V；板厚 1.6 |
| `paw3395.kicad_pcb` | Edge.Cuts 外形 **15.45 × 28.0 mm**（R1 圆角）；U2 封装位置 → 光学中心偏板中心约 **4.6 mm**（沿长边） |
| `paw3395_pcb.pretty/PAW3395.kicad_mod` | 16 脚 THT，脚距范围 10.7 × 13.35；PCB 开窗 **8.6 × 17.26**；镜头底面占位 B.CrtYd **19.0 × 21.75**（相对光学中心 X −9.5…+9.5，Y −11.02…+10.73）；两处光学中心标记 (5.35, 5.66)/(5.35, 4.56) |

用途：传感器定位框内开口按镜头占位 19.0×21.75 加间隙取 21×25；转接板外形作为“自制主板”方案的参考包络。
注意：这是 PAW3395/3950 **转接板**的尺寸，不代表任何供体主板，也不代表 PAW3950 封装本体尺寸。
